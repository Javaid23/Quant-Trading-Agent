# Quant Trading Agent Demo Script

## 1. Opening pitch (20–30 seconds)

"This is a paper-trading options intelligence agent built for the Alpaca AI Trading Agents Hackathon. It continuously evaluates a stock, generates a bullish, bearish, or neutral signal using a small, explainable set of indicators, and then chooses an options strategy based on that signal and portfolio risk."

## 2. Problem we are solving (30–40 seconds)

"Most retail traders react too late or rely on emotion. We wanted to build an assistant that gives a structured, explainable trading decision: signal first, risk second, execution third. Importantly, it does this in a paper trading environment and keeps decisions understandable to the user."

## 3. Live app walkthrough (60–90 seconds)

1. Open the dashboard and select a ticker such as AAPL.
2. Explain that the app reads market data and evaluates technical signals.
3. Show the signal card and the risk score.
4. Point to the recommended options strategy such as long call or long put.
5. Highlight the decision rationale, which explains why the agent chose the trade.

"This is not a black-box model. It is deterministic logic with a plain-language explanation layer."

## 4. Risk defense mode (30–40 seconds)

"Once a position is open, the system monitors portfolio risk. If risk rises too high, it can shift into a hedging mode or exit the position to protect capital. That makes the system more realistic than a one-step signal bot."

## 5. Why this matters (20–30 seconds)

"This project combines signal generation, risk management, and options execution into one coherent system. It is explainable, controlled, and built for paper trading before moving to a higher-stakes environment."

## 6. Closing statement (10–15 seconds)

"This is a practical AI trading assistant that turns technical analysis into a structured options decision process — explainable, disciplined, and ready for deeper live-market automation."
